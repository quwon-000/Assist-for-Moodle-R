# 動作確認

新しいバージョンを公開する前に、実際の moodle+R で確認する項目です。仕組みについては [architecture.md](architecture.md) を見てください。

## 確認の前に

- `chrome://extensions`（Edge は `edge://extensions`）で拡張機能を再読み込みし、エラーが出ていないことを確かめます。
- moodle+R にログインし、一度ダッシュボードを開きます。
- 画面を保存して確認に使う場合、保存したページには氏名や履修科目が入ります。リポジトリには入れないでください（`.gitignore` で `*moodle+R.html` と `*moodle+R_files/` を除外しています）。スクリーンショットを公開するときは、サンプルデータに置き換えてください。

## チェックリスト

### ダッシュボード

- [ ] 左にタイムライン、右に時間割が並び、1画面に収まる
- [ ] 「標準 | ワイド」で再読み込みなしに切り替わり、再読み込み後も選んだ表示が残る
- [ ] 授業のない土曜日の列と、授業のない最終時限の行が隠れる
- [ ] ブラウザの幅を 1200px 未満にすると、標準の表示に戻る
- [ ] 編集モードをオンにすると、標準の表示に戻る
- [ ] タイムラインか時間割のブロックを非表示にしても、片側が空いたままにならない
- [ ] Moodle の言語を English にしても崩れない

### コースページ

- [ ] トピック形式のコースで、回が2列のカードで並ぶ
- [ ] 「シラバス」ボタンで正しい授業のシラバスが新しいタブで開く（初回は約1.5秒、2回目からはすぐ）
- [ ] 合同開講の授業では、授業コードごとにシラバスボタンが出る
- [ ] 「私の先生にメッセージ」がある授業で、上部に先生の名前が出て、押すとメッセージ入力画面が開く

### 教材の一括ダウンロード

- [ ] 一覧に「ファイル」、「フォルダ」の中身、説明文や「ページ」の添付が回ごとに並ぶ
- [ ] 回の見出しのチェックを外すと、教材の選択は変わらず、その回の教材が回のフォルダを作らずに科目のフォルダへ保存される。入れ直すと、その回の教材にもチェックが入る
- [ ] 「すべて選択」「すべて解除」で、回の見出しのチェックも一緒に切り替わる
- [ ] 「課題」に先生が添付した資料が一覧に並び、自分が提出したファイルとフィードバックのファイルは並ばない
- [ ] 提出画面にだけ表示される資料（「提出中のみファイルを表示する」設定や「活動の指示」のファイル）も一覧に並ぶ。一覧を出したあとも、課題の提出状況が「未提出」のまま変わらない
- [ ] 「第1回」などの回のページに教材がある授業で、その回の教材も一覧に並ぶ
- [ ] 実際に保存したファイルが、HTML ではなく PDF などの教材そのものである
- [ ] 保存先が、1件なら `ダウンロード/` 直下、同じ回だけなら `ダウンロード/<回>/`、複数の回なら `ダウンロード/<科目>/<回>/` になる
- [ ] 「フォルダ」の中のファイルが、フォルダの構造を保って保存される
- [ ] 保存中にダイアログを閉じても最後まで保存され、拡張機能アイコンの件数が「✓」になる
- [ ] 「ダウンロードを中止」で残りが保存されない
- [ ] 上部の「フォルダ」のチェックを外すと、回の見出しのチェックがすべて外れ、すべて「ダウンロード」直下に保存される。次に開いたときも外れたままになっている
- [ ] 上部の名前の欄に入れた名前のフォルダに保存され、科目のフォルダ名は次回も残る
- [ ] 回の見出しの名前を書き換えると、その名前の回のフォルダに保存され、次回も同じ名前が入っている
- [ ] 2つのオプションの状態が、ダイアログを開き直しても残る

### そのほか

- [ ] ブックマークから moodle+R を開くとダッシュボードが開き、ナビバーの「Home」を押すと Home が表示される
- [ ] ナビバーの「リンク集」に CAMPUS WEB があり、開ける
- [ ] タイムラインの課題を「非表示」にすると隠れ、絞り込みの変更や「さらに活動を表示する」のあとも隠れたままになる
- [ ] 「非表示」を押すと確認の画面が出て、「キャンセル」では隠れない
- [ ] 「すべて元に戻す」で、隠した課題がまとめて戻る。「個別に選ぶ」→「元に戻す」で1件ずつ戻る
- [ ] ストア版と読み込み版の両方を有効にしても、ボタンやバーが2つにならない
- [ ] 新しいプロファイルに読み込むと、案内ページが1回だけ開く
