# Assist for moodle+R

立命館大学の LMS「moodle+R」を、パソコンで使いやすくする Chrome / Edge 拡張機能です。
開いた瞬間に、締め切りの近い課題と今週の時間割が1画面にそろいます。

Chrome ウェブストア: https://chromewebstore.google.com/detail/lgofkcacddfpoepkfiabigmiihmflppn?utm_source=item-share-cb

> **非公式**の拡張機能です。立命館大学とは関係ありません。
> 成績や提出物を変更したり、勝手に提出したりすることはありません。

![ダッシュボードのワイド表示（サンプルデータ）](assets/スクリーンショット_1280x800/2-dashboard.png)

## できること

1. **時間割と課題を1画面に**: ダッシュボードを画面幅いっぱいに広げ、左に課題、右に時間割を並べます。
2. **コースページを広く見やすく**: 授業のページの第1回・第2回…を2列で並べます。
3. **標準 | ワイド の切り替え**: いつでも moodle+R 本来の表示に戻せます。
4. **シラバスをワンクリックで**: 授業のページの「シラバス」ボタンから、その授業のシラバスを開きます。
5. **教材を一括ダウンロード**: 授業の教材を回ごとの一覧から選び、まとめて保存できます。
6. **先生にすぐメッセージ**: 「私の先生にメッセージ」を授業のページの上部に表示します。
7. **Home を飛ばす**: ブックマークから開くと、ダッシュボードが直接開きます。
8. **リンク集に CAMPUS WEB**: ナビバーのリンク集から CAMPUS WEB を開けます。
9. **タイムラインの課題を非表示**: 関係のない課題を、ダッシュボードの課題一覧から隠せます。

それぞれの詳しい説明は「[機能の詳しい説明](#機能の詳しい説明)」、うまく動かないときは「[困ったときは](#困ったときは)」を見てください。

## 動作環境

- **ブラウザ**: Google Chrome または Microsoft Edge（パソコン版）
- **画面の幅**: 2列の表示は、ブラウザの横幅が **1200px 以上**のときに使われます。それより狭いときは、自動で moodle+R の標準の表示になります。「シラバス」ボタンや教材の一括ダウンロードなどは、画面の幅に関係なく使えます。
- moodle+R の **編集モード**がオンのときは、標準の表示になります。

## インストール

インストールは [Chrome ウェブストア](https://chromewebstore.google.com/detail/lgofkcacddfpoepkfiabigmiihmflppn?utm_source=item-share-cb) からがおすすめです（自動で更新されます）。
ここでは、GitHub から入れる方法を説明します。

### 1. ダウンロードして展開する

1. GitHub のリポジトリの **Releases** を開き、最新版の **Assets** にある `assist-for-moodle-r-v○○.zip` をダウンロードします。
2. zip を右クリックして「すべて展開」し、できたフォルダを **消さない場所** に置きます。
   - おすすめ: `ドキュメント\Assist for moodle+R`
   - インストール後にこのフォルダを移動・削除すると、拡張機能が動かなくなります。

> 緑色の「Code」→「Download ZIP」でダウンロードした場合は、展開した中の **`extension` フォルダ** を使ってください。

### 2. ブラウザに読み込む

| 手順 | Google Chrome | Microsoft Edge |
| --- | --- | --- |
| 1. 拡張機能の画面を開く | アドレスバーに `chrome://extensions` | アドレスバーに `edge://extensions` |
| 2. デベロッパーモードをオン | 右上のスイッチ | 左側のスイッチ |
| 3. 読み込む | 「パッケージ化されていない拡張機能を読み込む」 | 「展開して読み込み」 |
| 4. フォルダを選ぶ | 手順1で置いたフォルダ（`manifest.json` が入っているフォルダ） | 同左 |

読み込むと、使い始めの案内ページが開きます。案内にしたがって、moodle+R のダッシュボードを一度開けば準備完了です。

> ブラウザの起動時に「デベロッパーモードの拡張機能を無効にする」という案内が出ることがあります。無効にせずに閉じてください。

### 3. 更新する

Chrome ウェブストアから入れた場合は、自動で更新されます。GitHub から入れた場合は、次の手順で更新します。

1. Releases から新しい zip をダウンロードして展開します。
2. **前と同じフォルダ** の中身を、新しいものに置き換えます。
3. 拡張機能の画面（`chrome://extensions`）で、この拡張機能の再読み込みボタン（↻）を押します。

同じフォルダを使えば、保存してあるシラバスの URL や表示の設定はそのまま引き継がれます（フォルダの場所が変わると、別の拡張機能として扱われて設定が消えます）。

## 機能の詳しい説明

### 1. 時間割と課題を1画面に

ダッシュボードを開くと、**左に課題（タイムライン）、右に時間割**が並びます。スクロールしなくても、締め切りの近い課題と今週の時間割がすぐに確認できます。

- 時間割は画面に収まるように詰めて表示します。
  - 長い科目名は2行までに省略します。
  - お気に入り・未読・未提出のアイコンは、該当するもの（点灯しているもの）だけを表示します。
  - 6限に授業が1つもないときは、6限の行を表示しません。
  - 土曜日に授業が1つもないときは、土曜日の列を表示しません（その分、他の曜日が広くなります）。
- 課題が多いときは、課題の欄の中だけでスクロールできます。
- 「コース概要」は、課題と時間割の下にあります。

### 2. コースページを広く見やすく

時間割の科目をクリックして開くコースページも、画面の幅いっぱいに広がります。第1回・第2回…の各回が **2列のカード**で並ぶので、多くの回を一度に見られます。

### 3. 標準 | ワイド の切り替え

画面右上（通知アイコンの左）にある **「標準 | ワイド」** ボタンで、いつでも表示を切り替えられます。

- **ワイド**: 画面の幅いっぱいに使い、2列で表示します（この拡張機能の表示）。
- **標準**: moodle+R の標準の表示です。
- ダッシュボードとコースページで、それぞれ別に切り替えられます。選んだ表示は記憶され、次に開いたときもそのままです。

### 4. シラバスをワンクリックで

コースページの科目名の下にある **「シラバス」ボタン**を押すと、その授業のシラバス（大学が公開している学外向けのもの）が新しいタブで開きます。

- 1つの科目に授業コードが複数ある合同開講の授業では、授業コードごとにボタンが表示されます。
- 初めて開く授業では「シラバスを開いています…」と表示され、1〜2秒ほどで切り替わります。2回目からはすぐに開きます。

### 5. 教材を一括ダウンロード

コースページの **「教材を一括ダウンロード」** ボタンを押すと、そのページの教材が回ごとに一覧で表示されます。チェックを付けた教材を、まとめてパソコンに保存できます。

- 最初はすべての教材にチェックが付いています。「すべて解除」を押してから、必要なものだけ選ぶこともできます。
- 保存先は、選んだ教材によって変わります（ダイアログの上部に表示されます）。ファイル名は、先生がアップロードしたときの名前のままです。同じ名前のファイルがあるときは「(1)」などが付きます。

  | 選んだ教材 | 保存先 |
  | --- | --- |
  | 1件だけ | 「ダウンロード」フォルダに直接（例: `ダウンロード/講義資料.pdf`） |
  | 2件以上で、すべて同じ回 | 回の名前のフォルダ（例: `ダウンロード/第1回/講義資料.pdf`） |
  | 2件以上で、複数の回にまたがる | 科目名のフォルダの中に回ごと（例: `ダウンロード/科目名/第1回/講義資料.pdf`） |

- 対象は、次のものです。外部サイトへのリンクは対象外です。
  - 「ファイル」の教材
  - 「フォルダ」の中のファイル（フォルダの形のまま保存されます。一覧では「解答/answer.sql」のように表示されます）
  - 説明文や「ページ」の中に貼られたファイル
  - 「課題」に先生が添付した資料（提出画面にだけ表示される資料も含みます。自分が提出したファイルやフィードバックは含みません）
- コースページに「第1回」などのリンクだけがあり、教材がその先の回のページにある科目でも、各回のページの教材がまとめて一覧に入ります（回が多いと、一覧が出るまで数秒かかります）。
- ダウンロード中は「3 / 12 件完了」のように進み具合が表示されます。
- **ダウンロードを始めたら、ダイアログを閉じても、別のページへ移動しても、保存は最後まで続きます。** 残りの件数はブラウザの拡張機能アイコンに表示され、終わると「✓」（失敗があったときは「!」）に変わります。
- 途中でやめたいときは、ダイアログを閉じる前に「ダウンロードを中止」を押してください。保存中だった1件を除き、残りは保存しません。
- **フォルダ名の変更**: 上部の「フォルダ」の横の欄で、一番上に作るフォルダ（科目のフォルダ、または回のフォルダ）の名前を変えられます。科目のフォルダの名前は科目ごとに記憶され、次回も同じ名前になります。
- **回ごとのフォルダ**: 「第1回」などの回の見出しの名前を書き換えると、その回のフォルダの名前を変えられます（科目ごとに記憶され、次回も同じ名前になります）。回の見出しのチェックを外すと、その回のフォルダは作らず、教材は科目のフォルダに直接保存します（教材の選択はそのままです）。チェックを入れ直すと、その回の教材にもすべてチェックが入ります。「すべて選択」「すべて解除」では、回の見出しのチェックも一緒に切り替わります。
- **フォルダを作らない**: 上部の「フォルダ」のチェックを外すと、回の見出しのチェックもすべて外れ、フォルダを1つも作らずに、すべて「ダウンロード」フォルダに直接保存します（選んだ状態は次回も引き継がれます）。
- 教材を探すときに「ページ」「フォルダ」「課題」や課題の提出画面を裏で開くため、自分で開いたときと同じく閲覧の記録が残ります（先生のログに「閲覧」「提出フォームを表示」と記録され、完了条件が「閲覧」の活動はチェックが付くことがあります）。提出の状態が変わったり、提出されたりすることはありません。小テストは開きません。

> ダウンロードした教材は、自分の学習のためだけに使ってください。他の人に渡したり、インターネットに公開したりしないでください。

### 6. 先生にすぐメッセージ

コースページの「私の先生にメッセージ」は、普段は閉じている右側のメニューの中にあります。この中の先生の名前を、コースページ上部（「シラバス」などのボタンの下）にも **「先生にメッセージ: ○○先生」** として表示します。押すと、いつもと同じメッセージ入力画面が開きます。

- 先生が「私の先生にメッセージ」を設定していない授業では表示されません。

### 7. Home を飛ばす

ブックマークなどから moodle+R を開いたときに表示される **Home（サイトのトップ）を飛ばして、ダッシュボードを直接開きます。**

- moodle+R の中でナビバーの「Home」や左上のロゴを押したときは、いつもどおり Home が表示されます。

### 8. リンク集に CAMPUS WEB

画面上部の **「リンク集」** に **CAMPUS WEB** を追加しました（「学び支援サイト」の下）。

### 9. タイムラインの課題を非表示

ダッシュボードの左の課題一覧（タイムライン）で、課題にマウスを乗せると **「非表示」** ボタンが出ます。押すと確認の画面が出て、**「非表示にする」** を押すとその課題を一覧から隠します。

- 同じ活動の「開始」と「締め切り」は、別々に隠せます。
- 日付の下の課題がすべて隠れると、日付の見出しも隠れます。
- 一覧の一番下の **「すべて元に戻す」** を押すと、隠した課題をまとめて一覧に戻せます。
- 1件だけ戻すときは **「個別に選ぶ」** を押すと隠した課題が薄く表示されるので、その課題の **「元に戻す」** を押します。
- 隠した記録は、半年たつと自動で消えます。

## 困ったときは

**表示が崩れている・見づらい**
画面右上の「標準」を押すと、moodle+R の標準の表示に戻ります。大学側で moodle+R の画面が変更されると、表示が崩れることがあります。

**「標準 | ワイド」ボタンが見当たらない**
ブラウザの横幅が狭いか、編集モードがオンになっている可能性があります。ウィンドウを広げるか、編集モードをオフにしてください。

**「シラバス」ボタンが表示されない**
一度ダッシュボードを開いてから、時間割の科目をクリックしてコースページを開き直してください。時間割に載っていない授業では、ボタンが出ないことがあります。
「シラバス」と「教材を一括ダウンロード」のボタンは、科目のトップページ（コースページ）に表示されます。「第1回」などの回のページには表示されないので、コースページに戻ってから使ってください。

**シラバスが開かず、シラバスの検索画面が表示された**
その授業のシラバスが見つからなかったか、複数の候補が見つかった場合です。表示された検索結果から授業を選んでください。1〜3月は年度の切り替わりの関係で、見つからないことがあります。

**教材のダウンロードに失敗した**
ダイアログに失敗した教材の名前が表示されます。moodle+R のログインが切れていることがあるので、ページを再読み込みしてログインし直してから、もう一度試してください。閲覧が制限されている教材は、一覧に表示されません。
TA など、その科目の編集権限を持っている場合は、「ファイル」の教材が失敗になることがあります（Moodle の仕様で、編集権限のある人にはファイルが直接渡されないため）。その場合は教材を個別に開いて保存してください。

**拡張機能が動かなくなった**
拡張機能の画面（`chrome://extensions`）でエラーが表示されていないか、オンになっているかを確認してください。GitHub から入れていてフォルダを移動・削除した場合は、「インストール」の「2. ブラウザに読み込む」からやり直してください。

## アンインストール

拡張機能の画面（`chrome://extensions` または `edge://extensions`）で、「Assist for moodle+R」の **「削除」** を押してください。保存されていた情報もすべて消えます。GitHub から入れた場合は、その後、展開したフォルダを削除してかまいません。

```

│  ├ layout-toggle.js/.css    「標準 | ワイド」の切り替え
│  ├ dashboard.css            ダッシュボードの2列表示と時間割
│  ├ course.css               コースページの2列表示と各ボタン・ダイアログ
│  ├ course-syllabus.js       シラバスボタン
│  ├ syllabus-search.js       シラバスサイトでの自動検索
│  ├ materials-download.js    教材の一括ダウンロード（教材を集めて一覧を表示）
│  ├ background.js            教材の保存・フォルダ分け・案内ページの表示
│  ├ course-teachers.js       「私の先生にメッセージ」を上部に表示
│  ├ home-skip.js             Home を飛ばしてダッシュボードへ
│  ├ campusweb-link.js        リンク集に CAMPUS WEB を追加
│  ├ timetable-courses.js     時間割から授業コードを覚える
│  └ welcome.html/.css/.js    インストール直後の案内ページ
├ docs/
│  ├ architecture.md        仕組みと設計（コードを読む人・手を入れる人向け）
│  └ testing.md             公開前の動作確認チェックリスト
├ CHANGELOG.md      変更履歴
├ assets/           Chrome ウェブストア用の画像と説明文（すべてサンプルデータ）
├ PRIVACY.md        プライバシーポリシー
└ .github/workflows/release.yml   リリース用 zip の自動作成
```

## 開発

- ビルドは不要です（素の JavaScript と CSS、Manifest V3）。
- コードを変えたら、拡張機能の画面で再読み込み（↻）して確かめます。
- 仕組みや設計の判断は [docs/architecture.md](docs/architecture.md) にまとめています。
- 新しいバージョンを公開する前に、[docs/testing.md](docs/testing.md) のチェックリストで実際の moodle+R で確認します。
- 変更内容は [CHANGELOG.md](CHANGELOG.md) に追記します。

## プライバシー

利用者の情報を外部に送信することはありません。

- ブラウザ内に保存するのは、次の情報だけです。
  - 開いたことのある授業のシラバスの URL（次回すぐ開くため）
  - 時間割の授業と授業コードの対応（シラバスボタンのため）
  - 選んだ表示（「標準」か「ワイド」か）
  - 教材ダウンロードの設定（フォルダを作るかどうか）と、科目ごと・回ごとのフォルダ名
  - タイムラインで非表示にした課題（課題名・科目名・非表示にした日時。半年で自動的に消えます）
- 「ダウンロードの管理」の許可は、選んだ教材をフォルダに分けて保存するためだけに使います。ほかのダウンロードには関与しません。

詳しくは [PRIVACY.md](PRIVACY.md) を見てください。
