# Assist for moodle+R 使い方ガイド

moodle+R（立命館大学の LMS）を、パソコンで見やすく使いやすくするための Chrome / Edge 拡張機能です。

> この拡張機能は個人が作成した非公式のものです。立命館大学とは関係ありません。
> moodle+R の見た目を変えるだけで、成績や提出物などのデータには一切触れません。

---

## できること

### 1. ダッシュボードが1画面で見渡せる

ダッシュボードを開くと、**左に課題（タイムライン）、右に時間割**が並びます。スクロールしなくても、締め切りの近い課題と今週の時間割がすぐに確認できます。

- 時間割は画面に収まるように詰めて表示します。
  - 長い科目名は2行までに省略します。
  - お気に入り・未読・未提出のアイコンは、該当するもの（点灯しているもの）だけを表示します。
  - 6限に授業が1つもないときは、6限の行を表示しません。
  - 土曜日に授業が1つもないときは、土曜日の列を表示しません（その分、他の曜日が広くなります）。
- 課題が多いときは、課題の欄の中だけでスクロールできます。
- 「コース概要」は、課題と時間割の下にあります。

### 2. コースページが広く見やすくなる

時間割の科目をクリックして開くコースページも、画面の幅いっぱいに広がります。第1回・第2回…の各回が **2列のカード**で並ぶので、多くの回を一度に見られます。

### 3. 表示を元に戻せる（レイアウトの切り替え）

画面右上（通知アイコンの左）にある **「標準 | ワイド」** ボタンで、いつでも表示を切り替えられます。

- **ワイド**: 画面の幅いっぱいに使い、2列で表示します（この拡張機能の表示）。
- **標準**: moodle+R の標準の表示です。

- ダッシュボードとコースページで、それぞれ別に切り替えられます。
- 選んだ表示は記憶され、次に開いたときもそのままです。

### 4. 授業のシラバスをすぐ開ける

コースページの科目名の下にある **「シラバス」ボタン**を押すと、その授業のシラバスが新しいタブで開きます。

- 1つの科目に授業コードが複数ある合同開講の授業では、授業コードごとにボタンが表示されます（例: 「シラバス（53528）」「シラバス（53529）」）。
- 初めて開く授業では「シラバスを開いています…」と表示され、1〜2秒ほどで切り替わります。2回目からはすぐに開きます。

### 5. リンク集から CAMPUS WEB を開ける

画面上部の **「リンク集」** に **CAMPUS WEB** を追加しました（「学び支援サイト」の下）。

### 6. 教材をまとめてダウンロードできる

コースページの **「教材を一括ダウンロード」** ボタンを押すと、そのページの教材が回ごとに一覧で表示されます。チェックを付けた教材を、まとめてパソコンに保存できます。

- 最初はすべての教材にチェックが付いています。「すべて解除」を押してから、必要なものだけ選ぶこともできます。
- 保存先は、ブラウザの「ダウンロード」フォルダの中の **`科目名/回の名前/`** です。
  - ファイル名は、先生がアップロードしたときの名前のままです。同じ名前のファイルがあるときは「(1)」などが付きます。
- 対象は、**「ファイル」の教材**、**「フォルダ」の中のファイル**、**説明文や「ページ」の中に貼られたファイル**、**「課題」に先生が添付した資料**（提出画面にだけ表示される資料も含む）です（自分が提出したファイルやフィードバックは含みません）。外部サイトへのリンクは対象外です。
  - コースページに「第1回」などのリンクだけがあり、教材がその先の回のページにある科目でも、各回のページの教材がまとめて一覧に入ります（回が多いと、一覧が出るまで数秒かかります）。
  - 「フォルダ」の中のファイルは、フォルダの形のまま保存されます。一覧では、サブフォルダの中のファイルが「解答/answer.sql」のように表示されます。
- ダウンロード中は「3 / 12 件完了」のように進み具合が表示されます。
- **ダウンロードを始めたら、ダイアログを閉じても、別のページへ移動しても、保存は最後まで続きます。** 残りの件数はブラウザの拡張機能アイコンに表示され、終わると「✓」（失敗があったときは「!」）に変わります。
- 途中でやめたいときは、ダイアログを閉じる前に「ダウンロードを中止」を押してください。保存中だった1件を除き、残りは保存しません。
- 教材を探すときに「ページ」「フォルダ」「課題」や課題の提出画面を裏で開くため、自分で開いたときと同じく閲覧の記録が残ります（先生のログに「閲覧」「提出フォームを表示」と記録され、完了条件が「閲覧」の活動はチェックが付くことがあります）。提出の状態が変わったり、提出されたりすることはありません。

> ダウンロードした教材は、自分の学習のためだけに使ってください。他の人に渡したり、インターネットに公開したりしないでください。

### 7. 先生へのメッセージをすぐ送れる

コースページの「私の先生にメッセージ」は、普段は閉じている右側のメニューの中にあります。この中の先生の名前を、コースページ上部（「シラバス」などのボタンの下）にも **「先生にメッセージ: ○○先生」** として表示します。押すと、いつもと同じメッセージ入力画面が開きます。

- 先生が「私の先生にメッセージ」を設定していない授業では表示されません。

### 8. Home を飛ばしてダッシュボードを開く

ブックマークなどから moodle+R を開いたときに表示される **Home（サイトのトップ）を飛ばして、ダッシュボードを直接開きます。**

- moodle+R の中でナビバーの「Home」や左上のロゴを押したときは、いつもどおり Home が表示されます。

## 動作環境

- **ブラウザ**: Google Chrome または Microsoft Edge（パソコン版）
- **画面の幅**: 2列の表示は、ブラウザの横幅が **1200px 以上**のときに使われます。
  - それより狭いとき（ウィンドウを小さくしたときなど）は、自動で moodle+R の標準の表示になります。
  - 「シラバス」ボタンと CAMPUS WEB のリンクは、画面の幅に関係なく使えます。
- moodle+R の **編集モード**がオンのときは、標準の表示になります。

## インストール方法

Chrome ウェブストアで公開した後は、ストアからのインストールをおすすめします（自動で更新されます）。
GitHub から入れる場合は、フォルダを読み込んで使います。最初に1回だけ設定が必要です。

1. GitHub のリポジトリの **Releases** から、最新版の `assist-for-moodle-r-v○○.zip` をダウンロードします。
2. zip を右クリックして「すべて展開」し、できたフォルダを **パソコンの消さない場所**（例: `ドキュメント\Assist for moodle+R`）に置きます。
   - インストール後にフォルダを移動したり削除したりすると、拡張機能が動かなくなります。
3. Chrome または Edge のアドレスバーに次のように入力して開きます。
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
4. **「デベロッパーモード」をオン**にします（Chrome は右上、Edge は左側にあります）。
5. **「パッケージ化されていない拡張機能を読み込む」**（Edge では「展開して読み込み」）を押し、手順2のフォルダ（`manifest.json` が入っているフォルダ）を選びます。
6. 使い始めの案内ページが開きます。案内にしたがって、拡張機能をツールバーに固定し、moodle+R にログインして **一度ダッシュボードを開いてください**。時間割の授業が読み込まれ、コースページでシラバスボタンが使えるようになります。

> ブラウザの起動時に「デベロッパーモードの拡張機能を無効にする」といった案内が出ることがあります。その場合は、無効にせずに閉じてください。

## 使い方

| やりたいこと | 操作 |
| --- | --- |
| 課題と時間割をまとめて見る | ダッシュボードを開く |
| 標準の表示とワイド表示を切り替える | 画面右上の「標準 \| ワイド」を押す |
| 授業のページを開く | 時間割の科目名をクリック |
| シラバスを見る | コースページの科目名の下の「シラバス」を押す |
| CAMPUS WEB を開く | 画面上部の「リンク集」→「CAMPUS WEB」 |
| 教材をまとめて保存する | コースページの「教材を一括ダウンロード」→ 教材を選んで「ダウンロード」 |
| 先生にメッセージを送る | コースページ上部の「先生にメッセージ:」の先生の名前を押す |
| Home を見る | moodle+R の中でナビバーの「Home」を押す（外から開いたときはダッシュボードが開きます） |

## 困ったときは

**表示が崩れている・見づらい**
画面右上の「標準」を押すと、moodle+R の標準の表示に戻ります。大学側で moodle+R の画面が変更されると、表示が崩れることがあります。

**「標準 | ワイド」ボタンが見当たらない**
ブラウザの横幅が狭いか、編集モードがオンになっている可能性があります。ウィンドウを広げるか、編集モードをオフにしてください。

**「シラバス」ボタンが表示されない**
一度ダッシュボードを開いてから、時間割の科目をクリックしてコースページを開き直してください。時間割に載っていない授業では、ボタンが出ないことがあります。
「シラバス」と「教材を一括ダウンロード」のボタンは、科目のトップページ（コースページ）に表示されます。「第1回」などの回のページには表示されないので、コースページに戻ってから使ってください。

**シラバスが開かず、シラバスの検索画面が表示された**
その授業のシラバスが見つからなかったか、複数の候補が見つかった場合です。表示された検索結果から授業を選んでください。1〜3月は年度の切り替わりの関係で、見つからないことがあります。

**教材のダウンロードに失敗した**
ダイアログに失敗した教材の名前が表示されます。moodle+R のログインが切れていることがあるので、ページを再読み込みしてログインし直してから、もう一度試してください。閲覧が制限されている教材は、一覧に表示されません。
TA など、その科目の編集権限を持っている場合は、「ファイル」の教材が失敗になることがあります（Moodle の仕様で、編集権限のある人にはファイルが直接渡されないため）。その場合は教材を個別に開いて保存してください。

**拡張機能を更新したい**
Releases から新しい zip をダウンロードして展開し、**前と同じフォルダ** の中身を新しいものに置き換えてから、拡張機能の一覧（`chrome://extensions`）で、この拡張機能の **再読み込みボタン（↻）** を押してください。
同じフォルダを使えば、保存してあるシラバスの URL や表示の設定はそのまま引き継がれます。別の場所に置いて読み込み直すと、別の拡張機能として扱われ、設定が消えます。
バージョン 0.8.0 から「ダウンロードの管理」の許可が増えたため、更新時に許可を求められることがあります。教材の保存先フォルダを決めるために使う許可です。

**拡張機能が動かなくなった**
拡張機能の一覧でエラーが表示されていないか、オンになっているかを確認してください。フォルダを移動・削除した場合は、インストール方法の手順4からやり直してください。

## プライバシーについて

- この拡張機能は、あなたの情報を外部に送信しません。
- ブラウザ内に保存するのは、次の情報だけです。
  - 開いたことのある授業のシラバスの URL（次回すぐ開くため）
  - 時間割の授業と授業コードの対応（シラバスボタンのため）
  - 選んだ表示（「標準」か「ワイド」か）
- シラバスは、大学が公開している「オンラインシラバス（学外向け）」を開いています。
- 「ダウンロードの管理」の許可は、教材を `科目名/回の名前/` のフォルダに分けて保存するためだけに使います。ほかのダウンロードには関与しません。

---

## アンインストール

拡張機能の一覧（`chrome://extensions` または `edge://extensions`）で、「Assist for moodle+R」の **「削除」** を押してください。保存されていた情報もすべて消えます。その後、`extension` フォルダを削除してかまいません。
